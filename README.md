# Nafis — демо интернет-магазина

Демо от [CaravanHouse](https://caravanhouse.uz): магазин вымышленного бренда натуральной косметики.
Живая версия: https://store.caravanhouse.uz

Что показывает демо:
- **Каталог**: категории, фильтр по типу кожи и цене, сортировка, поиск из шапки, бейджи «Хит / Новинка / Скидка», избранное.
- **Быстрый просмотр**: выбор объёма с пересчётом цены, способ применения, ключевые компоненты.
- **Корзина**: изменение количества, промокод `DEMO20` (−20%), полоса «до бесплатной доставки».
- **Оформление заказа** в три шага: контакты → доставка (курьер, регионы, самовывоз) → оплата.
- **Панель продавца** (`/ru/admin`): заказы за сегодня, выручка, средний чек, смена статусов; ваш заказ появляется там сразу после оформления.
- Русский и узбекский (`/ru`, `/uz`), адаптивная вёрстка.

Это демо: бренд, товары и цены придуманы, картинки упаковок нарисованы в SVG (`components/ProductArt.tsx`), заказы и оплата не проводятся — корзина и заказы хранятся в `localStorage`. В настоящем проекте здесь каталог из админки или 1С, онлайн-оплата, уведомления в Telegram и интеграция с доставкой.

Стек: Next.js 16, React 19, TypeScript, Tailwind CSS 4. Хостинг — Vercel.

```bash
npm install
npm run dev   # http://localhost:3000
```

Хотите такой магазин — [напишите нам в Telegram](https://t.me/CaravanHousebot?start=demo_store).
